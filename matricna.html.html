Zadatak

Rešiti po \(X\) matričnu jednačinu \[ D + (X-C)F = 2I, \] gde je

\[ D=\begin{bmatrix}1&-2&0\\3&-1&-4\\0&-1&1\end{bmatrix},\quad C=\begin{bmatrix}-4&3&-1\\0&-1&5\\-2&0&1\end{bmatrix},\quad F=\begin{bmatrix}-2&0&1\\0&3&-1\\-2&-1&1\end{bmatrix}, \]

a \(I\) je jedinična matrica reda 3.

Ideja

Izdvajamo \(X\) iz jednačine koristeći pravila matrične algebre. Množenje matrica nije komutativno, pa je bitno da se \((X-C)F\) oslobađa matrice \(F\) množenjem sa desne strane inverznom matricom \(F^{-1}\):

\[ (X-C)F = 2I - D \;\;\Longrightarrow\;\; X - C = (2I-D)\,F^{-1} \;\;\Longrightarrow\;\; X = C + (2I-D)\,F^{-1}. \]

Pre toga proveravamo da \(F\) ima inverz, tj. da je \(\det F \neq 0\).

Rešenje

Korak 1: Determinanta matrice \(F\)

\[ \det F = -2\begin{vmatrix}3&-1\\-1&1\end{vmatrix} + 1\cdot\begin{vmatrix}0&3\\-2&-1\end{vmatrix} = -2(3-1) + (0+6) = -4 + 6 = 2 \neq 0, \]

pa matrica \(F\) ima inverznu.

Korak 2: Inverzna matrica \(F^{-1}\)

Računanjem kofaktora dobijamo adjungovanu matricu, a kako je \(\det F = 2\):

\[ F^{-1}=\frac{1}{\det F}\,\operatorname{adj}F =\frac12\begin{bmatrix}2&-1&-3\\2&0&-2\\6&-2&-6\end{bmatrix} =\begin{bmatrix}1&-\tfrac12&-\tfrac32\\[2pt]1&0&-1\\[2pt]3&-1&-3\end{bmatrix}. \]

Korak 3: Matrica \(2I - D\)

\[ 2I - D = \begin{bmatrix}2&0&0\\0&2&0\\0&0&2\end{bmatrix} - \begin{bmatrix}1&-2&0\\3&-1&-4\\0&-1&1\end{bmatrix} = \begin{bmatrix}1&2&0\\-3&3&4\\0&1&1\end{bmatrix}. \]

Korak 4: Proizvod \((2I-D)\,F^{-1}\)

\[ (2I-D)F^{-1} = \begin{bmatrix}1&2&0\\-3&3&4\\0&1&1\end{bmatrix} \begin{bmatrix}1&-\tfrac12&-\tfrac32\\[2pt]1&0&-1\\[2pt]3&-1&-3\end{bmatrix} = \begin{bmatrix}3&-\tfrac12&-\tfrac72\\[2pt]12&-\tfrac52&-\tfrac{21}{2}\\[2pt]4&-1&-4\end{bmatrix}. \]

Korak 5: Sabiranje sa \(C\)

\[ X = C + (2I-D)F^{-1} = \begin{bmatrix}-4&3&-1\\0&-1&5\\-2&0&1\end{bmatrix} + \begin{bmatrix}3&-\tfrac12&-\tfrac72\\[2pt]12&-\tfrac52&-\tfrac{21}{2}\\[2pt]4&-1&-4\end{bmatrix} = \begin{bmatrix}-1&\tfrac52&-\tfrac92\\[2pt]12&-\tfrac72&-\tfrac{11}{2}\\[2pt]2&-1&-3\end{bmatrix}. \]

Odgovor

Rešenje matrične jednačine \(D + (X-C)F = 2I\) je:

\[ X=\begin{bmatrix}-1&\tfrac52&-\tfrac92\\[4pt]12&-\tfrac72&-\tfrac{11}{2}\\[4pt]2&-1&-3\end{bmatrix} \]
