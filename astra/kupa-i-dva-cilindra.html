Kupa i dva cilindra

Odrediti površinu dela kupe S₁ koji pripada granici tela i zapreminu tela ograničenog zadatim površima.

S₁: z² = x² + y²
S₂: x² + y² = 1
S₃: x² + (y − 1)² = 1
01 / IZBOR TELA

Najpre preciziramo oblast

Uzimamo zajedničku unutrašnjost oba cilindra i prostor između dve grane kupe:

T = {(x, y, z) : x² + y² ≤ 1,
x² + (y − 1)² ≤ 1, −√(x² + y²) ≤ z ≤ √(x² + y²)}.

Same jednačine površi ne određuju stranu svake granice. Ovo rešenje koristi navedeno tumačenje. Kupa ima dve grane, pa P(S₁) obuhvata obe. Ne traži se ukupna površina tela sa cilindričnim delovima.

02 / PROJEKCIJA NA XY-RAVAN

Presek dva jedinična kruga

Projekcija D je sočivo:

D: x² + y² ≤ 1,
x² + (y − 1)² ≤ 1.

Oduzimanjem jednačina kružnica dobijamo 2y − 1 = 0, pa su preseci:

A, B = (±√3/2, 1/2).

Centri su O(0, 0) i C(0, 1), a oba poluprečnika su 1.

03 / POLARNE KOORDINATE

Granica se menja pri φ = π/6 i 5π/6

x = r cos φ,   y = r sin φ,   dx dy = r dr dφ.

Prvi cilindar daje r ≤ 1. Drugi daje:

r² − 2r sin φ ≤ 0   ⇒   0 ≤ r ≤ 2 sin φ.

Zato je 0 ≤ φ ≤ π, a radijalna granica je R(φ) = min(1, 2 sin φ). Jednačina 2 sin φ = 1 daje uglove π/6 i 5π/6.

R(φ) = 2 sin φ,   0 ≤ φ ≤ π/6;
R(φ) = 1,   π/6 ≤ φ ≤ 5π/6;
R(φ) = 2 sin φ,   5π/6 ≤ φ ≤ π.

Oblast je simetrična u odnosu na y-osu, pa krajnja dva intervala daju jednake integrale.

04 / POVRŠINA DELA KUPE

Element površine je √2 dx dy

Za gornju granu z = f(x,y) = √(x² + y²), van temena važi:

fx = x/√(x² + y²),   fy = y/√(x² + y²),
√(1 + fx² + fy²) = √2.

Teme je jedna tačka i ne utiče na površinski integral. Donja grana ima istu površinu, pa:

P(S₁) = 2√2 ∬D dx dy = 2√2 · |D|.

Površinu projekcije računamo u polarnim koordinatama:

|D| = ½ ∫0π R(φ)² dφ
= 4 ∫0π/6 sin²φ dφ + π/3
= 4 [φ/2 − sin(2φ)/4]0π/6 + π/3
= 2π/3 − √3/2.
P(S₁) = 4π√23 − √6 ≈ 3,474354.
05 / ZAPREMINA

Visina tela iznad (x, y) jednaka je 2r

Granice po z su −r i r. Sa Jakobijanom r dobijamo:

V = ∫0π ∫0R(φ) ∫−rr r dz dr dφ
= 2 ∫0π ∫0R(φ) r² dr dφ
= ⅔ ∫0π R(φ)³ dφ
= ⅔ [16 ∫0π/6 sin³φ dφ + 2π/3].

Preostali integral računamo smenom u = cos φ:

∫0π/6 sin³φ dφ = [−cos φ + cos³φ/3]0π/6
= ⅔ − 3√3/8.

Uvrštavanjem sledi:

V = 64 + 4π9 − 4√3 ≈ 1,579171.
REZULTAT / OBE GRANE KUPE

Površina S₁ i zapremina tela

P(S₁) = 4π√23 − √6
V = 64 + 4π9 − 4√3

Oba rezultata odnose se na telo T definisano u prvom koraku.

Ako se misli samo na gornju polovinu

Za dodatni uslov 0 ≤ z ≤ √(x² + y²), ravan z = 0 zatvara polovinu tela. Površina gornjeg dela kupe i zapremina tada su upola manje:

P(S₁⁺) = 2π√23 − √62
V+ = 32 + 2π9 − 2√3.

P(S₁⁺) ne uključuje ravnu osnovu u z = 0.
