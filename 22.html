Zadatak

Odrediti oblast definisanosti funkcija:

a) \( y=\sqrt{\dfrac{3+x}{3-x}} \);      b) \( y=\sqrt{x-\dfrac{1}{x}} \);

v) \( y=\sqrt{\dfrac{x+5}{4x-x^{2}-3}} \);      g) \( y=\sqrt{\dfrac{x^{2}+3x-4}{6-x-x^{2}}} \).

Ideja

Uslov za kvadratni koren količnika je da količnik bude nenegativan: \( \dfrac{A(x)}{B(x)}\geq 0 \). Koristimo tablicu znaka: odredimo nule brojioca i imenioca, podelimo realnu osu na intervale i utvrdimo znak količnika u svakom intervalu. Tačke gde je brojilac nula uključujemo (\( \geq 0 \)), a tačke gde je imenilac nula isključujemo.

Rešenje

a) \( y=\sqrt{\dfrac{3+x}{3-x}} \)

Uslov: \( \dfrac{3+x}{3-x}\geq 0 \). Nule: brojilac \( x=-3 \), imenilac \( x=3 \) (isključeno).

\( x \)\( (-\infty,-3) \)\( -3 \)\( (-3,3) \)\( 3 \)\( (3,+\infty) \)
\( 3+x \)\( - \)\( 0 \)\( + \)\( + \)\( + \)
\( 3-x \)\( + \)\( + \)\( + \)\( 0 \)\( - \)
\( \dfrac{3+x}{3-x} \)\( - \)\( 0 \)\( + \)n.def.\( - \)

\[ D=[-3,3) \]

b) \( y=\sqrt{x-\dfrac{1}{x}} \)

Sređujemo: \( x-\dfrac{1}{x}=\dfrac{x^{2}-1}{x}=\dfrac{(x-1)(x+1)}{x} \). Uslov: \( \dfrac{(x-1)(x+1)}{x}\geq 0 \). Nule: \( x=-1,1 \), imenilac \( x=0 \) (isključeno).

\( x \)\( (-\infty,-1) \)\( -1 \)\( (-1,0) \)\( 0 \)\( (0,1) \)\( 1 \)\( (1,+\infty) \)
\( x-1 \)\( - \)\( - \)\( - \)\( - \)\( - \)\( 0 \)\( + \)
\( x+1 \)\( - \)\( 0 \)\( + \)\( + \)\( + \)\( + \)\( + \)
\( x \)\( - \)\( - \)\( - \)\( 0 \)\( + \)\( + \)\( + \)
\( \dfrac{(x-1)(x+1)}{x} \)\( - \)\( 0 \)\( + \)n.def.\( - \)\( 0 \)\( + \)

\[ D=[-1,0)\cup[1,+\infty) \]

v) \( y=\sqrt{\dfrac{x+5}{4x-x^{2}-3}} \)

Imenilac: \( 4x-x^{2}-3=-(x^{2}-4x+3)=-(x-1)(x-3) \). Uslov: \( \dfrac{x+5}{-(x-1)(x-3)}\geq 0 \) tj. \( \dfrac{x+5}{(x-1)(x-3)}\leq 0 \). Nule: brojilac \( x=-5 \), imenilac \( x=1,3 \) (isključeno).

\( x \)\( (-\infty,-5) \)\( -5 \)\( (-5,1) \)\( 1 \)\( (1,3) \)\( 3 \)\( (3,+\infty) \)
\( x+5 \)\( - \)\( 0 \)\( + \)\( + \)\( + \)\( + \)\( + \)
\( x-1 \)\( - \)\( - \)\( - \)\( 0 \)\( + \)\( + \)\( + \)
\( x-3 \)\( - \)\( - \)\( - \)\( - \)\( - \)\( 0 \)\( + \)
\( \dfrac{x+5}{(x-1)(x-3)} \)\( - \)\( 0 \)\( + \)n.def.\( - \)n.def.\( + \)

\[ D=(-\infty,-5]\cup(1,3) \]

g) \( y=\sqrt{\dfrac{x^{2}+3x-4}{6-x-x^{2}}} \)

Brojilac: \( x^{2}+3x-4=(x+4)(x-1) \). Imenilac: \( 6-x-x^{2}=-(x^{2}+x-6)=-(x+3)(x-2) \). Uslov: \( \dfrac{(x+4)(x-1)}{-(x+3)(x-2)}\geq 0 \) tj. \( \dfrac{(x+4)(x-1)}{(x+3)(x-2)}\leq 0 \). Nule: brojilac \( x=-4,1 \), imenilac \( x=-3,2 \) (isključeno).

\( x \)\( (-\infty,-4) \)\( -4 \)\( (-4,-3) \)\( -3 \)\( (-3,1) \)\( 1 \)\( (1,2) \)\( 2 \)\( (2,+\infty) \)
\( x+4 \)\( - \)\( 0 \)\( + \)\( + \)\( + \)\( + \)\( + \)\( + \)\( + \)
\( x-1 \)\( - \)\( - \)\( - \)\( - \)\( - \)\( 0 \)\( + \)\( + \)\( + \)
\( x+3 \)\( - \)\( - \)\( - \)\( 0 \)\( + \)\( + \)\( + \)\( + \)\( + \)
\( x-2 \)\( - \)\( - \)\( - \)\( - \)\( - \)\( - \)\( - \)\( 0 \)\( + \)
\( \dfrac{(x+4)(x-1)}{(x+3)(x-2)} \)\( + \)\( 0 \)\( - \)n.def.\( + \)\( 0 \)\( - \)n.def.\( + \)

\[ D=[-4,-3)\cup[1,2) \]
